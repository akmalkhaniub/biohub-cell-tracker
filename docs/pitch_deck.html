Division Acceptance Constraints

Candidate daughter pairs must strictly satisfy three physical laws:

  • Spatial Proximity: $\|\vec{p}_{\text{daughter}} - \vec{p}_{\text{parent}}\| \le 12\,\mu\text{m}$.
  • Volume Conservation: $0.85 \le \frac{V_1 + V_2}{V_{\text{parent}}} \le 1.15$.
  • Temporal Continuity: Pre-mitotic elongation phase in frame $t-1$.
# Hungarian Bipartite Cost Formula
C(i, j) = w_dist * ||p_i - p_j||_2
         + w_vol * |V_i - V_j| / max(V)
         + w_vel * ||v_pred - (p_j - p_i)||_2
